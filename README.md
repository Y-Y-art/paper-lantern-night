# Paper Lantern Night
A 3D night-market lantern flyer.

Third-person endless flyer. Pilot a paper lantern over a night market.
Tilt through arches, dodge fireworks and hanging signs, catch wish slips.

Vite + TypeScript + Three.js. Static. No backend.

## Play

npm i
npm run dev

npm run build
npm run preview

## Controls
- Mouse or WASD: tilt
- Space: burst
- Touch-drag on mobile
- R restart, M mute, P pause

## Design
Chunked night market, procedural meshes, wish slips, fireworks, paifang gates.
Score = distance + wishes + gate bonus. Best in localStorage.
Vite + TypeScript + Three.js. Static, no backend.
